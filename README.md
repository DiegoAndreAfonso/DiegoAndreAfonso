## Projetos em destaque

### 1. Gestão Jurídica / Central Jurídica

Sistema web voltado à organização da rotina de escritórios de advocacia, reunindo funcionalidades para gestão de clientes, processos, agenda e outras atividades administrativas.

Desenvolvido em parceria com **Kennedy Pinheiro**, o projeto envolve planejamento de funcionalidades, desenvolvimento de interfaces e integração entre frontend e backend.

**Tecnologias:** Next.js · React · TypeScript · Material UI · Laravel · PHP · MySQL

🔗 [Acessar o sistema](https://advogadosmca.com.br/)

*O acesso às funcionalidades do sistema depende de autenticação.*

### 2. Pela Ordem

Aplicação desenvolvida durante um **hackathon**, em equipe, para auxiliar na organização de pautas de audiências a partir de planilhas exportadas do eproc.

A solução importa arquivos XLS, XLSX e CSV, considera impedimentos, agrupa audiências de cada advogado em horários consecutivos e sinaliza conflitos de agendamento. Ao final, permite exportar a pauta organizada em XLSX.

**Tecnologias:** Next.js · React · TypeScript · Tailwind CSS · SheetJS · ExcelJS

🔗 [Experimentar o Pela Ordem](https://pelaordem.advogadosmca.com.br/)

*O acesso à demonstração é público, sem login. Os dados de trabalho são mantidos temporariamente durante a utilização da aplicação.*

### 3. Lousa

Protótipo de uma plataforma educacional voltada a professores, com recursos para organizar materiais, elaborar questões e disponibilizar atividades aos alunos.

O projeto contempla um painel do professor e um fluxo de participação, correção e liberação de resultados. Foi desenvolvido em colaboração com **Kennedy Pinheiro e Alice Figueira**.

**Tecnologias:** React · TypeScript · Vite

*O projeto está em estágio de protótipo, com dados locais e serviços simulados.*
